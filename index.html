ВИД СВЕРХУ

Сравниваем тень штанги конвертора с тенью шеста: в нужный момент они параллельны.

ВИД СБОКУ

Солнце ниже спутника, поэтому по солнцу находим только азимут. Угол места доводим в конце по сигналу модема.

ДОНАВЕДЕНИЕ «ЗМЕЙКОЙ»

Шаг по углу места 0,5–1°, на каждом шаге поводим по азимуту влево-вправо. Пятно — луч спутника: чем ближе к центру, тем сильнее сигнал.

ВИД ИЗ-ЗА АНТЕННЫ

Так видит установщик: солнце должно оказаться точно по центру за зеркалом.
