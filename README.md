# sun-pointing

Тестовый проект Да-Телеком.

- `index.html` — главная: «Помощник установщика» (азимут, угол места, поворот конвертора, наклон зеркала, время наведения по солнцу, компас).
- `sun.html` — анимация наведения по солнцу (3D + виды сверху, сбоку, донаведение «змейкой», вид сзади зеркала антенны).
- `compass.html` — анимация наведения по компасу в смартфоне и пошаговая инструкция.
- `magnetic.html` — анимация наведения по магнитному компасу (стрелку на «С», направление на спутник — по числу на шкале) и пошаговая инструкция.
- `fonts/` — шрифт Raleway (SIL OFL), подключён локально, как на satfinder.
- `dtk.css` — общий стиль сервисов Да-Телеком (как на satfinder.da-tele.com): шрифт Raleway, цвета, шапка с навигацией.
- `video.html` — сборка вертикального видео (MP4, 720×1280) для клиента из трёх анимаций для выбранной точки, спутника и даты. Видео собирается прямо в браузере (WebCodecs + mp4-muxer); анимации открываются во скрытом iframe с параметром `rec=1` и рисуются покадрово.

Статический сайт без сборки, публикуется на Netlify из ветки `main`. Старый адрес `/helper.html` перенаправляется на главную.
