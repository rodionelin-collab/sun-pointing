# sun-pointing

Тестовый проект Да-Телеком.

- `index.html` — главная: «Помощник установщика» (азимут, угол места, поворот конвертора, наклон зеркала, время наведения по солнцу, компас).
- `sun.html` — анимация наведения по солнцу (3D + виды сверху, сбоку, донаведение «змейкой», вид из-за антенны).
- `compass.html` — анимация наведения по компасу в смартфоне и пошаговая инструкция.

Статический сайт без сборки, публикуется на Netlify из ветки `main`. Старый адрес `/helper.html` перенаправляется на главную.
