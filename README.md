# sun-pointing

Тестовый проект Да-Телеком.

- `index.html` — анимация наведения спутниковой антенны по солнцу (3D + виды сверху, сбоку, донаведение «змейкой», вид из-за антенны).
- `compass.html` — анимация наведения по компасу (3D + компас, вид сверху, «змейка», вид из-за антенны).
- `helper.html` — «Помощник установщика»: азимут, угол места, поворот конвертора, наклон зеркала, время наведения по солнцу, компас.

Статический сайт без сборки, публикуется на Netlify из ветки `main`.
